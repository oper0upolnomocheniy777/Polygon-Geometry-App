Polygon Geometry Application
Приложение для работы с полигонами, аффинными преобразованиями и геометрическими алгоритмами.

🚀 Функциональность

Базовые операции
✅ Создание полигонов через клики мышью

✅ Очистка сцены (удаление всех полигонов)

✅ Визуализация полигонов, вершин и ребер

Аффинные преобразования (реализованы через матрицы)
✅ Смещение на dx, dy

✅ Поворот вокруг заданной пользователем точки

✅ Поворот вокруг своего центра

✅ Масштабирование относительно заданной пользователем точки

✅ Масштабирование относительно своего центра

Геометрические алгоритмы
✅ Поиск точки пересечения двух ребер

✅ Проверка принадлежности точки выпуклому/невыпуклому полигону

✅ Классификация положения точки относительно ребра (справа/слева)

🛠 Технологии
Python 3.8+

Pygame - для графического интерфейса

NumPy - для матричных операций

📦 Установка

Клонируйте репозиторий:
git clone https://github.com/your-username/polygon-geometry-app.git
cd polygon-geometry-app

Создайте виртуальное окружение (рекомендуется):
python -m venv venv
venv\Scripts\activate  # Windows

Установите зависимости:
pip install -r requirements.txt


🎮 Использование
Запустите приложение:
python main.py

Управление:
Левый клик - добавить точку полигона

Правый клик - завершить полигон

Колесо мыши - выбрать полигон для преобразований

Панель инструментов - выбор операций и ввод параметров
